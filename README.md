# CTVU own EPG

TV guide for TiviMate, built every hour from the provider's channel list (no myepg).

Guide address (never changes):
https://raw.githubusercontent.com/Cabletvunleashed/CTVU-EPG-OWN/main/epg.xml.gz

- Real listings: provider's own guide (by tvg-id), then free guides (same-country name match).
- Every other channel: a placeholder showing the channel name.
- `report.json`: counts from the latest build.
